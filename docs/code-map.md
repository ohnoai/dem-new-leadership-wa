# Code map

The public application is a static site.

| Path | Role |
| --- | --- |
| `index.html` | Page structure and interface |
| `app.js` | The three steps, drafts, progress, sharing and erase |
| `model.js` | Pure draft state, restoration, and recipient overrides |
| `data.js` | Washington officials and reference data |
| `campaign.js` | Editable campaign language, share text and tip jar settings |
| `districts.js` | ZIP code to congressional district data, generated by `scripts/build-zip-districts.js` |
| `tips.js` | Optional tip jar (Ko-fi and Lightning), shown only on the hosts in `campaign.js` |
| `confetti.js` | Finish celebration, skipped under reduced motion |
| `icons.js` | Share-button brand marks (Simple Icons, CC0) |
| `vendor/` | Third-party code: `qrcode-generator` 1.4.4 (MIT), loaded only for Lightning QR codes |
| `styles.css` | Mobile-first presentation and Washington visual identity |
| `assets/` | Original evergreen, self-hosted headline font and font license |
| `scripts/serve.js` | Local-only development preview server |
| `scripts/build-zip-districts.js` | Builds `districts.js` from the Census ZIP/district relationship file |
| `tests/` | Node model tests and Playwright browser/accessibility tests |
| `playwright.config.js` | Mobile and desktop browser test configurations |
| `docs/sources.md` | Primary-source contact and district research |
| `docs/contact-forms.md` | Dated browser form compatibility audit, evidence and unknowns |
| `docs/verification.md` | Executed verification and outstanding checks |
| `README.md` | Campaign introduction and first steps |
| `docs/development.md` | Local development, draft mechanics and hosting |
| `docs/adapting.md` | Instructions for bringing the campaign to another state |
| `LICENSE` | MIT license |

Update this map when the public application structure changes.
